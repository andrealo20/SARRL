# v2.5: Panda reference validation and shared scoring

This release validates the cumulative constant-delay reference and reports
its control-cycle cost. A separate causal shared-parameter scoring comparison
fails its frozen screen. The cumulative bank remains the reference.

The [reference results](panda-reference-results.md) retain 4,000 fresh episodes
after reproducing all 1,920 v2.4 records. The bank completed 1,000/1,000 tasks,
selected every final delay correctly and passed every per-cell/per-joint
criterion, with zero measured physical violations. On 30,000 saved-input
cycles, p99 was 1.827530 ms and the maximum was 3.928535 ms against a 10 ms
period. Plant stepping, construction, I/O and serialization are excluded;
these timings describe the recorded host and workload.

The [shared-scoring results](panda-shared-scoring-results.md) retain another
1,920 episodes after reproducing all 4,000 validation records. The candidate
completed 316/320 tasks and recovered 96/160 changing final ages, against
79/160 for score-only memory. Age gain, constant-age correctness, success and
per-joint tracking criteria failed. The candidate does not advance to
confirmation or change defaults.

## Components and scope

| Component | Status |
|---|---|
| `PandaDelayController(predict=False)` | Validated reference on the declared constant-delay grid |
| `PandaSharedScoreController` | Causal experimental candidate retained for reproduction; failed screen |
| Reference validation | Fifty paired seeds, twenty conditions and four arms; seed-block bootstrap intervals |
| Saved-input profiling | Thirty thousand retained cycle durations, host/runtime provenance and audit |
| Shared-scoring comparison | Twenty paired seeds, sixteen conditions and six arms; causal innovation replay |

The new evidence covers simulated joint trajectories, two sampled posture
ranges and on-grid delays from 0 to 40 ms. Zero measured violations do not
certify safety outside that grid. Changing latency remains unresolved. No
Panda residual policy, seven-joint safety filter or hardware result is added.
The supplied SVG banner and existing demonstrations are preserved.

## Installation example

From this release's checkout:

```bash
python -m pip install -e '.[mujoco]'
python examples/panda_reach.py
```

The nominal example uses an existing engineering-test seed, writes no files
and checks installation rather than adding benchmark evidence.

## Audit retained evidence

Frozen source commits remain reachable in release history. From a clone
named `SARRL`, use separate source worktrees and the recorded numerical runtime:

```bash
git worktree add --detach ../SARRL-reference-audit 09858a7
cd ../SARRL-reference-audit
# Use Python 3.12 and one numerical thread per process.
python -m pip install -e '.[mujoco]' 'numpy==2.5.2' 'mujoco==3.13.0'
python -m tools.audit_panda_reference_validation \
  --input ../SARRL/results/panda_reference_validation
python -m tools.profile_panda_reference --audit \
  --input ../SARRL/results/panda_reference_validation \
  --output ../SARRL/results/panda_reference_profile
cd ../SARRL
git worktree add --detach ../SARRL-shared-audit 1a47469
cd ../SARRL-shared-audit
python -m pip install -e '.[mujoco]' 'numpy==2.5.2' 'mujoco==3.13.0'
python -m tools.audit_panda_shared_scoring \
  --input ../SARRL/results/panda_shared_scoring_pilot
```

The audits check 5,920 new records, 176 traces, 140 causal estimator replays
and 30,000 durations without new physical episodes. Completion/source hashes
and discrete identities are exact; floating-point replay uses recorded
tolerances. Retained seed blocks are used and completed outputs are never
replaced. CI runs these audits from their recorded source worktrees.
