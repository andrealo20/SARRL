# v2.6: joint filtering and adaptive residual evaluation

This release completes two separate controlled studies. Both candidates fail
their frozen advancement criteria. The cumulative constant-delay Panda bank
and the planar adaptive/covariance-margin controller remain the references.

The [Panda joint-filter study](panda-joint-filter-results.md) reproduced all
4,000 v2.5 reference records before 480 fresh episodes. On fast moves, unsafe
episodes fell from 104/120 to 20/120, but filtered control aborted 107/120
tasks and succeeded in 13/120 against 16/120 for cumulative control. Ordinary
moves retained 120/120 successes per arm without measured violations or
aborts. Remaining physical violations and lost successes prevent advancement.

The [planar residual study](adaptive-residual-results.md) trained five final
SAC policies for 200,000 calls each, then evaluated all five against fixed
and adaptive baselines on 100 paired tasks across three scenarios. Its 2,100
held-out records show a primary success difference of -24.6 percentage
points against adaptive control, with 95% interval [-32.2, -17.3]. All five
model-level primary differences are negative. This recipe does not justify
Panda residual integration.

## Components and scope

| Component | Status |
|---|---|
| Cumulative Panda delay bank | Retained reference on the validated constant-delay grid |
| `PandaFilteredController` | Experimental joint-position/velocity/torque projection; failed screen |
| `AdaptiveMarginResidualEnv` | Separate planar training wrapper with the existing covariance margin |
| Five trained residuals | Complete fixed budgets; failed held-out screen; local model hashes retained |
| Public audits | Frozen-source data, pairing, trace and decision checks; planar inference requires local weights |

The Panda filter covers joint constraints and uses bounded braking on
infeasibility. General collision avoidance is outside that formulation.
Planar physical-envelope checks sample control boundaries; Panda traces retain
every physical substep. Neither study establishes hardware safety or
sim-to-real performance. Existing figures, replay videos and the supplied SVG
banner are preserved.

## Audit the retained studies

Use separate source worktrees so later package changes do not alter replay
arithmetic. From a clone named `SARRL`, first audit Panda with Python 3.12
and the recorded numerical dependencies:

```bash
python -m pip install -e '.[mujoco]' 'numpy==2.5.2' 'mujoco==3.13.0' 'scipy==1.18.1'
git worktree add --detach ../SARRL-joint-audit 6891dd27edf8b28514160d1ade350e3213826058
python tools/audit_panda_joint_filter_portable.py \
  --source-checkout ../SARRL-joint-audit \
  --input results/panda_joint_filter_pilot
```

The portable auditor verifies 480 records, 24 causal controller replays,
36,000 recorded physical substeps and 1,846 feasible projections. Regenerated
floating commands use the recorded tolerance; delivered commands match the
retained FIFO exactly. Source and data hashes remain exact.

For planar statistics, create a separate Python 3.11.15 CPU environment using
the [recorded installation recipe](adaptive-residual-comparison.md#run-and-audit),
then run from the frozen source:

```bash
git worktree add --detach ../SARRL-residual-audit b41e167c2a609849c01031010e5710aa4801670f
cd ../SARRL-residual-audit
python -m tools.audit_planar_residual \
  --input ../SARRL/results/planar_residual_v26
# Add this option only when the original local training files are available:
# --models ../SARRL/results/planar_residual_v26/training
```

The public audit checks all 2,100 records, 21 traces and both comparisons of
the 300 historical records. Historical portable matches are 300/300; original
strict matches are 299/300, retained explicitly after the amendment made
before fresh training. The public audit reports inference unverified. With
the local ignored weights, the full audit also verifies model identities,
policy actions and causal stack replays. No fresh episode is opened by audits.
