# v2.4: changing-latency diagnosis and parameter memory

This release diagnoses retained Panda delay-bank failures and tests candidate
parameter forgetting while holding score memory fixed. The supplied SVG
banner is used unchanged. Existing demonstrations and planar control retain
their previous scope.

The [saved-trace diagnosis](panda-latency-diagnosis.md) covers all 48 bank
traces from the previous pilot. The [parameter-memory comparison](panda-estimator-memory.md)
reproduced 1,920 previous records before retaining 1,920 new paired episodes.
Joint memory completed 320/320 tasks without measured physical violations
and selected the final age in 99/160 changing cases, against 83/160 for
score-only memory. Its frozen changing-age and per-joint tracking criteria
failed. The cumulative bank remains the reference.

## Components and scope

| Component | Status |
|---|---|
| `PandaDelayController(predict=False)` | Constant on-grid delay alignment reference |
| `PandaJointMemoryController` | Experimental candidate retained for reproduction; fails this pilot's decision rule |
| `PandaForgettingRLS` | Bounded parameter updates with per-interval exponential forgetting |
| Saved-input diagnosis | Retrospective parameter fits, information conditioning and score resets |
| Comparison and audit commands | Frozen provenance, paired records, causal replay and completion hashes |

Estimator inverse information is not calibrated uncertainty. Parameter bounds
do not bound its covariance uniformly under missing excitation. Task success
does not establish correct packet-age selection. No Panda residual policy,
seven-joint safety filter, hardware or sim-to-real result is added.

## Installation example

From a checkout of this release:

```bash
python -m pip install -e '.[mujoco]'
python examples/panda_reach.py
```

The example runs the existing nominal engineering-test seed. It checks the
installation and API, writes no files and adds no benchmark evidence.
The [demo guide](demo.md) documents the saved-data videos.

## Audit the retained comparison

The campaign was frozen at `cee94b2`; this commit is preserved in release
history. From a clone named `SARRL`, use the recorded sources and numerical
runtime:

```bash
git worktree add --detach ../SARRL-memory-audit cee94b2
cd ../SARRL-memory-audit
# Use the recorded Python 3.12 runtime.
python -m pip install -e '.[mujoco]' 'numpy==2.5.2' 'mujoco==3.13.0'
python -m tools.audit_panda_estimator_memory \
  --input ../SARRL/results/panda_estimator_memory_pilot
```

The audit checks 1,920 records, 96 first-seed traces and 80 causal estimator
replays without new physical episodes. Hashes, cell identities and discrete
decisions are exact; floating-point replay uses the recorded reproduction
tolerances. Completed outputs are never replaced. Reopening the retained
seed block would not provide independent confirmation.
